### 정규표현식 연산자

|      Pattern       | 의미                                                                                | 예시 ( ✅: 일치,❌: 불일치 )                                                                                                                                                                       |
| :----------------: | :-------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|       **.**        | - "**\n**"( 줄바꿈 )  제외한 모든 문자 1개와 일치.<br>- ` re.DOTALL`사용 시 "**\n**"도 일치           | ✅ `re.search(".", "a")`  <br>❌ `re.search(".", "\n")`<br>✅ `re.search(".", "\n",re.DOTALL)`                                                                                               |
|      **^**RE       | - 문자열의 시작 부분이 RE와 일치<br>- `re.MULTILINE`사용 시  "**\n**" 이후도 시작으로 간주                | ✅ `re.search("^ab", "ab\ncd")`  <br>✅ `re.search("^ab", "cd\nab",`<br>                          `re.MULTILINE)`<br>❌ `re.search("^ab", "cd\nab")`                                         |
|      RE**$**       | - 문자열의 끝 또는 "**\n**" 바로 앞이 RE와 일치<br>- `re.MULTILINE`사용 시 각 줄의 끝( "\n" 앞)도 끝으로 간주 | ✅ `re.search("end$", "end")`<br>✅ `re.search("end$", "end\n")`<br>❌ `re.search("end$", "end\nabcd")`<br>✅ `re.search("end$", "end\nabcd", re.MULTILINE)`<br>❌ `re.search("end$", "abcd")` |
|      RE**\***      | - RE 0회 이상 반복됨                                                                    | pattern = ab*<br>- a==b==, a==bb==, a==bbb== : ✅<br>- a : ✅( b 가 없어도 일치됨 )                                                                                                                |
|      RE**+**       | - RE 1회 이상 반복됨                                                                    | pattern = ab+<br>- a==b==, a==bb==, a==bbb== : ✅<br>- a : ❌( b는 1개 이상부터 )                                                                                                                 |
|      RE**?**       | - RE 0 또는 1회 일치                                                                   | pattern = ab?<br>- a, a==b== : ✅<br>- abb : ❌                                                                                                                                             |
|    RE**{$m$}**     | - RE 정확히 $m$번 반복 일치                                                               | pattern = a{3}<br>- <mark>aaa</mark>, ==aaa==ab : ✅<br>- aa : ❌                                                                                                                           |
|   RE{**$m,n$**}    | - RE가 $m$번 이상 $n$번 이하 반복 일치<br>- RE{ , $n$} : $0-n$번                              | pattern = a{3,5}<br>- ==aaa== ,==aaaaa==b : ✅<br>- aa, aaaaaa : ❌<br><br>pattern = a{3, }<br>- ==aaa==, ==aaaaaaaaaa== : ✅<br><br>pattern = a{, 5}<br>- b, ==aaa==, ==aaaaaa==b : ✅       |
| RE{**$m,n$**}**?** | - RE가 $m$번 이상 $n$번 이하 반복만, 가능한 적은 반복 횟수 일치                                        |                                                                                                                                                                                           |
| RE{**$m,n$**}**+** | - RE가 $m$번 이상 $n$번 이하 반복만, 가능한 많은 반복 횟수 일치                                        |                                                                                                                                                                                           |
|       **\\**       | - 이스케이프 문자<br>- 표에 적힌 연산자를 문자로 취급하기 위해 사용                                         | pattern = \\\*<br>- ==\*== :✅<br><br>pattern =  *<br>- \* : ❌                                                                                                                             |
|      **\[\]**      | - 문자 집합을 나타내는 데 사용<br>- <br>- 문자 범위로 '-' 사용.                                      |                                                                                                                                                                                           |
