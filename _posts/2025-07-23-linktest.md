# 0. 정규표현식이란?
---
> [!정규표현식 ( Regex : Regular Expression )]
> 특정한 문자열의 패턴을 기술하는 언어
> 즉 어떤 문자열이 "패턴과 일치( True )"라고 판단하기 위한 규칙의 표현 방식
### 0.1. 어디에 사용하는가?
- 정해진 패턴이 있는 문자열을 찾기 위해서 사용
	- ex) 회원 가입 시 이메일 형식에 일치 하는 지 검증
	- ex) 
- 프로그래밍 언어에서 **변수명의 유효성 검증** 등에서도 사용됨
### 정규표현식 연산자

| **Pattern**<br>RE : 정규표현식 | **의미**                                                                                                                                                                                                                                                                                                                    | **예시** : re.search"패턴", "문자열")<br> - ✅: 문자열 내 해당 패턴이 있음<br> - ❌: 문자열 내 해당 패턴이 없음                                                                                                          |
| :-----------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|           **.**           | - "**\n**"( 줄바꿈 )  제외한 **모든 문자 1개**와 일치.<br>- ` re.DOTALL`사용 시 "**\n**"도 일치                                                                                                                                                                                                                                               | ✅ `re.search(".", "a")`  <br>❌ `re.search(".", "\n")`<br>✅ `re.search(".", "\n",re.DOTALL)`                                                                                               |
|          **^**RE          | - **문자열의 시작** 부분이 RE와 일치<br>- `re.MULTILINE`사용 시  "**\n**" 이후도 시작으로 간주                                                                                                                                                                                                                                                    | ✅ `re.search("^ab", "ab\ncd")`  <br>✅ `re.search("^ab", "cd\nab", re.MULTILINE)`<br>❌ `re.search("^ab", "cd\nab")`                                                                        |
|          RE**$**          | - **문자열의 끝** 또는 **"\n" 바로 앞**이 RE와 일치<br>- `re.MULTILINE`사용 시 각 줄의 끝( "\n" 앞)도 끝으로 간주                                                                                                                                                                                                                                     | ✅ `re.search("end$", "end")`<br>✅ `re.search("end$", "end\n")`<br>❌ `re.search("end$", "end\nabcd")`<br>✅ `re.search("end$", "end\nabcd", re.MULTILINE)`<br>❌ `re.search("end$", "abcd")` |
|         RE**\***          | - RE **0회 이상 반복** 일치                                                                                                                                                                                                                                                                                                      | ✅ `re.search("ab*", "a")`<br>✅ `re.search("ab*", "ab")`<br>✅ `re.search("ab*", "abbbb")`                                                                                                  |
|          RE**+**          | - RE **1회 이상 반복** 일치                                                                                                                                                                                                                                                                                                      | ❌ `re.search("ab+", "a")`<br>✅ `ressearchh("ab+", "ab")`<br>✅ `ressearchh("ab+", "abbbb")`                                                                                                |
|          RE**?**          | - RE **0 또는 1회** 일치                                                                                                                                                                                                                                                                                                       | ✅ `re.search("ab+", "a")`<br>✅ `re.search("ab+", "ab")`<br>❌ `re.search("ab+", "abbbb")`                                                                                                  |
|        RE**{$m$}**        | - RE $m$번 반복                                                                                                                                                                                                                                                                                                              | ❌ `re.search("a{3}", "aa")`<br>✅ `re.search("a{3}", "aaa")`<br>✅ `re.search("a{3}", "aaaaaaaa")`                                                                                          |
|       RE{**$m,n$**}       | - RE가 **$m$번 이상 $n$번 이하 반복** 일치<br>- RE{ , $n$} : **0번 이상 $n$번 이하 반복** 일치<br>- RE{ $m$, } : **$m$번 이상 반복** 일치                                                                                                                                                                                                             | ❌ `re.search("a{3,5}", "aa")`<br>✅ `re.search("a{3,5}", "aaa")`<br>✅ `re.search("a{3,5}", "aaaaaaaa")`                                                                                    |
|    RE{**$m,n$**}**?**     | - RE가 $m$번 이상 $n$번 이하 반복만, 가능한 적은 반복 횟수 일치                                                                                                                                                                                                                                                                                | `re.search("a{3,5}?", "aaaaa")`<br>    -> **search='==aaa=='**                                                                                                                            |
|    RE{**$m,n$**}**+**     | - RE가 $m$번 이상 $n$번 이하 반복만, 가능한 많은 반복 횟수 일치                                                                                                                                                                                                                                                                                | `re.search("a{3,5}+", "aaaaa")` <br>    -> **search='==aaaaa=='**                                                                                                                         |
|          **\\**           | - 이스케이프 문자<br>- 표의 1열에 적힌 연산자를 문자로 취급하기 위해 사용                                                                                                                                                                                                                                                                             | ❌ `re.search("*", "*")` -> 에러발생<br>✅ `re.search("\*", "*")`                                                                                                                               |
|        **\[...\]**        | - 문자 집합, 괄호 안 문자 중 하나와 일치<br>    - ex) \[abc\]는 'a', 'b', 'c' 중 하나와 일치<br>	- 이스케이프처럼 사용도 가능<br>	    - ex) \[\*\],  \[\\\],  \[&\] :  '\*', '\\', '&' 중 하나와 일치<br>- '-'로 **범위 지정** 가능<br>    - ex) \[a-z\]는 소문자 알파벳 중 하나.<br>	- 문자는 유니/아스키 코드상 작은 문자가 앞에 위치해야함<br>	    - \[가-힣\]은 한글 중 한 글자에 해당<br>		- ==\[힣-가\]==는 **오류** | ✅ `re.search("[abc]", "dog bat")`<br>✅ `re.search("[*]", "a*b")`<br>                                                                                                                      |
|       **\[^...\]**        | - **부정 문자 집합**, 괄호 안 문자 **외의 하나**와 일치<br>- 위의 괄호 문법처럼                                                                                                                                                                                                                                                                     |                                                                                                                                                                                           |
|       $A$**\|**$B$        | - $A$ RE 또는 $B$ RE와 일치                                                                                                                                                                                                                                                                                                    | ✅ `re.search("a\|b", "a")`<br>✅ `re.search("a\|b", "b")`<br>❌ `re.search("a\|b", "c")`                                                                                                    |
