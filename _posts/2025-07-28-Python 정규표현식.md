# 1. 정규표현식이란?
---
> [!정규표현식 ( Regex : Regular Expression )]
> - 특정한 문자열의 패턴을 기술하는 언어
> - 즉 어떤 문자열이 **"패턴과 일치"**라고 판단하기 위한 규칙의 표현 방식

### 1.1. 사용처
- 정해진 패턴이 있는 문자열을 찾기위해서 사용
	- ex) 회원 가입 시 이메일 형식에 일치 하는 지 검증
- 프로그래밍 언어에서도 **변수명의 유효성 검증** 등에서도 사용됨
	- ex) pyhon의 변수명은 첫글자 숫자 불가, keyword 안됨 등 패턴이 정해져 있음

# 2. Python의 정규표현식
---
- 정규표현식은 대부분의 언어에서 비슷한 문법을 공유하지만, 구현 방식이나 지원하는 기능은 언어마다 조금씩 차이 발생
- python에서 사용되는 정규표현식 문법 및 메소드를 기준으로 작성함
- [Python의 정규표현식 문서](https://docs.python.org/3.13/library/re.html#regular-expression-examples)
### 2.1. 구문( Syntax )

|       Pattern        | **의미**                                                                                                                                                                                                                                                                                                   | **예시** : ("패턴", "문자열")<br> - ✅: 문자열 내 해당 패턴이 있음<br> - ❌: 문자열 내 해당 패턴이 없음                                                                                                                  |
| :------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|        **.**         | - "**\n**"( 줄바꿈 )을 제외한 **임의의 문자 1개**와 일치.<br>- ` re.DOTALL`사용 시 "**\n**"도 일치                                                                                                                                                                                                                             | ✅ `re.search(".", "a")`  <br>❌ `re.search(".", "\n")`<br>✅ `re.search(".", "\n",re.DOTALL)`                                                                                               |
|      **^**$RE$       | - **문자열의 시작**이 $RE$와 일치<br>- `re.MULTILINE`사용 시 각 줄의 시작( "**\n**" 뒤 )도 시작으로 간주                                                                                                                                                                                                                           | ✅ `re.search("^ab", "ab\ncd")`  <br>❌ `re.search("^ab", "cd\nab")`<br>✅ `re.search("^ab", "cd\nab", re.MULTILINE)`                                                                        |
|      $RE$**$**       | - **문자열의 끝**이 $RE$와 일치<br>- `re.MULTILINE`사용 시 각 줄의 끝( "\n" 앞 )도 끝으로 간주                                                                                                                                                                                                                                  | ✅ `re.search("end$", "end")`<br>✅ `re.search("end$", "end\n")`<br>❌ `re.search("end$", "end\nabcd")`<br>✅ `re.search("end$", "end\nabcd", re.MULTILINE)`<br>❌ `re.search("end$", "abcd")` |
|      $RE$**\***      | - $RE$가 **0회 이상 반복**될 경우 일치                                                                                                                                                                                                                                                                              | ✅ `re.search("ab*", "a")`<br>✅ `re.search("ab*", "ab")`<br>✅ `re.search("ab*", "abbbb")`                                                                                                  |
|      $RE$**+**       | - $RE$가 **1회 이상 반복**될 경우 일치                                                                                                                                                                                                                                                                              | ❌ `re.search("ab+", "a")`<br>✅ `re.search("ab+", "ab")`<br>✅ `re.search("ab+", "abbbb")`                                                                                                  |
|      $RE$**?**       | - $RE$가 **0 또는 1회** 일치                                                                                                                                                                                                                                                                                   | ✅ `re.search("ab+", "a")`<br>✅ `re.search("ab+", "ab")`<br>❌ `re.search("ab+", "abbbb")`                                                                                                  |
|    $RE$**{$m$}**     | - $RE$가 **$m$번 반복될 경우** 일치                                                                                                                                                                                                                                                                               | ❌ `re.search("a{3}", "aa")`<br>✅ `re.search("a{3}", "aaa")`<br>✅ `re.search("a{3}", "aaaaaaaa")`                                                                                          |
|   $RE${**$m,n$**}    | - $RE$가 **$m$~$n$번 반복될 경우** 일치<br>- { , $n$} : **0~$n$번 반복될 경우** 일치<br>- {$m$, } : **$m$번 이상 반복될 경우** 일치                                                                                                                                                                                                 | ❌ `re.search("a{3,5}", "aa")`<br>✅ `re.search("a{3,5}", "aaa")`<br>✅ `re.search("a{3,5}", "aaaaaaaa")`                                                                                    |
| $RE${**$m,n$**}**?** | - $RE$가 **$m$~$n$번 반복될 경우**, **가능한 적은 반복 횟수**                                                                                                                                                                                                                                                            | `re.findall("a{3,5}?", "aaaaa")`<br>    -> `['aaa']`                                                                                                                                      |
| $RE${**$m,n$**}**+** | - $RE$가 **$m$~$n$번 반복될 경우**, **가능한 많은 반복 횟수**                                                                                                                                                                                                                                                            | `re.findall("a{3,5}+", "aaaaa")` <br>    -> `['aaaaa']`                                                                                                                                   |
|        **\\**        | - 이스케이프 문자<br>- 표의 1열에 적힌 연산자를 문자로 취급하기 위해 사용<br>- 메타 문자를                                                                                                                                                                                                                                                | ❌ `re.search("*", "*")` -> 오류<br>✅ `re.search("\*", "*")`                                                                                                                                 |
|     **\[...\]**      | - **문자 집합**, **괄호 안 문자** 중 하나와 **일치**<br>    - ex) \[abc\]는 'a', 'b', 'c' 중 하나와 일치<br>	- 이스케이프처럼 사용도 가능<br>	    - ex) \[\*\],  \[\$],  \[+\]<br>- '-'로 **범위 지정** 가능<br>    - ex) \[a-z\]는 소문자 알파벳 중 하나.<br>	- 문자는 유니/아스키 코드상 작은 문자가 앞에 위치해야함<br>	    - \[가-힣\]은 한글 중 한 글자에 해당<br>		- ==\[힣-가\]==는 **오류** | ✅ `re.search("[abc]", "a")`<br>❌ `re.search("[abc]", "d")`<br>✅ `re.search("[*]", "*")`<br>✅ `re.search("[a-z]", "f")`<br>✅ `re.search("[가-힣]", "뷁")`                                     |
|   **\[^$\dots$\]**   | - **부정 문자 집합**, **괄호 안 문자 제외**<br>- 위의 사용법과 같이 범위 지정도 가능                                                                                                                                                                                                                                                 | ❌ `re.search("[^abc]", "a")`<br>✅ `re.search("[^abc]", "d")`<br>❌ `re.search("[^*]", "*")`<br>❌ `re.search("[^a-z]", "f")`<br>❌ `re.search("[^가-힣]", "뷁")`                                |
|  $a$RE** \| **$b$RE  | - $a$ $RE$ 또는 $b$ $RE$와 일치                                                                                                                                                                                                                                                                               | ✅ `re.search("a\|b", "a")`<br>✅ `re.search("a\|b", "b")`<br>❌ `re.search("a\|b", "c")`                                                                                                    |
|        ($RE$)        | - 괄호 안 $RE$와 일치하는 문자열을 그룹 지정<br>- 그룹화된 문자열을 추출 가능                                                                                                                                                                                                                                                        | `re.search("(\d{2})-(\d{2})", "07-25")`<br>    -> `group(0)` = 07-25<br>	-> `group(1)` = 07<br>	-> `group(2)` = 25                                                                        |
|       (?:$RE$)       | - 그룹화는 하되 결과에 포함시키진 않음                                                                                                                                                                                                                                                                                   | `re.search("(?:\d{2})-(\d{2})", "07-25")`<br>    -> `group(0)` = 07-25<br>	-> `group(1)` = 25                                                                                             |
|      (?P<이름>RE)      | - 각 문자열 그룹에 이름을 붙여줌                                                                                                                                                                                                                                                                                      | `re.search("(?P<월>\d{2})-(?P<일>\d{2})", "07-25")`<br>	-> `group('월')` = 07<br>	-> `group('일')` = 25                                                                                       |
|       **\\숫자**       |                                                                                                                                                                                                                                                                                                          |                                                                                                                                                                                           |
|     **\\A**$RE$      | - **문자열 전체**에서 **시작 부분**이 **RE와 일치**<br>- '^' 보다 제한적                                                                                                                                                                                                                                                     | ✅ `re.search("\Aa", 'ab\ncd')`<br>❌ `re.search("\Aa", 'cd\nab', re.MULTILINE)`<br>✅ `re.search("^a", 'cd\nab', re.MULTILINE)`                                                             |
|       **\\b**        | - 빈 문자열을 가리킴<br>- 단어의 시작과 끝에 있는 문자열만 일치                                                                                                                                                                                                                                                                  |                                                                                                                                                                                           |
|       **\\B**        | -                                                                                                                                                                                                                                                                                                        |                                                                                                                                                                                           |
|       **\\d**        | - **10진수 숫자** 하나와 일치<br>- 정규표현식 "\[0-9\]" 와 같음                                                                                                                                                                                                                                                           | ✅ `re.search("\d", '1')`<br>❌ `re.search("\d", 'a')`                                                                                                                                      |
|       **\\D**        | - **10진수 숫자 외**의 문자와 일치<br>- 정규표현식 "\[^0-9\]" 와 같음                                                                                                                                                                                                                                                       | ❌ `re.search("\d", '1')`<br>✅ `re.search("\d", 'a')`                                                                                                                                      |
|       **\\s**        | - **공백 문자( ' ', '\\t', '\\n', '\\r', '\\f', '\\v')** 하나와 일치<br>- 정규표현식 **"\[ \\t\\n\\r\\f\\v\]" 와 같음**                                                                                                                                                                                                   | ✅ `re.search("\s", ' ')`<br>✅ `re.search("\s", '\n')`<br>❌ `re.search("\s", 'n')`                                                                                                         |
|       **\\S**        | - **공백 문자 외 문자** 하나와 일치<br>- 정규표현식 **"\[^ \\t\\n\\r\\f\\v\]" 와 같음**                                                                                                                                                                                                                                      | ❌ `re.search("\s", ' ')`<br>❌ `re.search("\s", '\n')`<br>✅ `re.search("\s", 'n')`                                                                                                         |
|       **\\w**        | - **숫자, 단어 문자** 하나와 일치<br>- **유니코드** 패턴이면 **알파벳, 한글 등등 모든 단어 문자**와 일치<br>- 특수 문자( @^&* 등 ), 공백 문자, 이모지 등 제외                                                                                                                                                                                              | ❌ `re.search("\w", ' ')`<br>❌ `re.search("\w", '\n')`<br>✅ `re.search("\w", 'n')`<br>✅ `re.search("\w", '가')`<br>❌ `re.search("\w", '@')`<br>❌ `re.search("\w", '😊')`                    |
|       **\\W**        | - **숫자, 단어 문자 외**의 문자와 일치                                                                                                                                                                                                                                                                                | ✅ `re.search("\W", ' ')`<br>✅ `re.search("\W", '\n')`<br>❌ `re.search("\W", 'n')`<br>❌ `re.search("\W", '가')`<br>✅ `re.search("\W", '@')`<br>✅ `re.search("\W", '😊')`                    |
|     **\\Z**$RE$      | - **문자열 전체**에서 **끝 부분**이 **RE와 일치**<br>- '$' 보다 제한적                                                                                                                                                                                                                                                      | ✅ `re.search("\Za", 'ab\ncd')`<br>❌ `re.search("\Za", 'cd\nab', re.MULTILINE)`<br>✅ `re.search("a$", 'cd\nab', re.MULTILINE)`                                                             |
